# softlight_assessment

Take home assessment for Softlight

Steps to run this project :

1. Create a python virtual environment :
   -> python3 -m venv venv
   -> source venv/bin/activate [activating the venv created above]

2. Install dependencies :
   -> pip install -r requirements.txt
   -> playwright install

3. Use the Makefile commands to run different workflows defined in the tasks.yaml
